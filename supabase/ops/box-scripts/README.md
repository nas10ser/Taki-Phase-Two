# سكربتات خادم جدة — نسخة مرجعية

هذه نسخٌ من سكربتات تعمل على خادم جدة في `/usr/local/sbin/`، محفوظةٌ هنا
للمراجعة والتاريخ. **المصدر الحيّ هو الخادم**، وأي تعديل يُطبَّق هناك ثم
يُحدَّث هنا.

| السكربت | الجدولة | ما يفعل |
|---|---|---|
| `taki-heartbeat.sh` | كل ١٠ دقائق (`/etc/cron.d/taki-heartbeat`) | يقيس القرص والذاكرة وعمر النسخة الاحتياطية، ويفحص الموقع والبوت، ويكتب الحكم في `system_heartbeat` — والتنبيه يصل تيليجرام خلال ثوانٍ |
| `taki-preview-keepalive.sh` | يومياً ٤:٠٥ص الرياض (`/etc/cron.d/taki-preview-keepalive`) | يوقظ قاعدة المعاينة (طوكيو) بطلب قراءة واحد — مشروع Supabase المجاني ينام بعد ٧ أيام بلا طلب |
| `taki-backup.sh` | ٣:٣٠ فجراً | النسخة الاحتياطية اليومية (موثّقة في `supabase/ops/RECOVERY.md`) |

🪤 **لماذا الفحص السريع على الخادم لا على GitHub:** جدولة GitHub Actions بذلُ
أفضل لا ضمان — قِست الفجوة الفعلية لمهمّة `*/10` فكانت **٢٠٥ دقيقة وسيطاً**
(أسوأها ٤١٤). وكرون هذا الخادم مُثبَتُ الانضباط: ٣٠٠٥٥ تشغيلاً لوظيفةٍ كل
دقيقتين بلا فشل واحد.
